# Electrical Distribution Network Design — Academic Group Project

**Author contribution:** Hareram Kumar, Jadavpur University, 2026.

This is an academic group analysis, not an independently authored complete network design.

## Design objectives

Plan a conceptual distribution network with LT and HT loads, transformer siting, seasonal demand curves, voltage regulation, loss and efficiency analysis and an academic capital cost estimate.

## Group-level results

- 305 mapped road segments across five sub-blocks.
- LT plan: five 2 MVA transformers; HT plan: one 4 MVA transformer.
- LT distributor length: 32.23 km; HT distributor length: 7.67 km.
- Total estimated capital cost in the original calculations: Rs 95.52 lakh.

## My contributions (from group report)

- Road-segment coordinate mapping.
- Transformer location for Sub-block 1.
- Seasonal hourly LT loading analysis for all five sub-blocks.
- Seasonal LT and HT load curve plots.
